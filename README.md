# DownLOL
[🔗](https://downlol.onrender.com/)

A OSS Web YT Downloader.
## Deploy:
Make sure to put your cookies.txt in ```/etc/secrets``` (Default ENV for Render)

Make it to point it to this repo and if the hosting supports it, it will automatically install using [Dockerfile](https://github.com/FlamrXD/DownLOL/blob/main/Dockerfile)
